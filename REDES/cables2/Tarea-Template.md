| Tipo / Especificación de la fibra       | Color de la chaqueta (jacket) / cable         |
| --------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------- |
| Monomodo (OS1, OS1a, OS2)| **Amarillo**|
| Multimodo OM1 (62.5/125) | **Naranja** |
| Multimodo OM2 (50/125)   | **Naranja** |
| Multimodo OM3 (50/125 láser-optimizado) | **Aqua (turquesa claro)**  |
| Multimodo OM4 (50/125 láser-optimizado) | **Aqua** (o violeta/magenta en algunos casos) |
| Multimodo OM5 (50/125 “wideband”)       | **Lima / verde lima**      |
| Monomodo (OS1 / OS2) | **Amarillo**|
| Multimodo OM1 / OM2  | **Naranja** |
| Multimodo OM3        | **Aqua (turquesa claro)** |
| Multimodo OM4        | **Violeta o magenta**     |
| Multimodo OM5        | **Lima (verde claro)**    |


La distancia depende del tipo de fibra y del equipo usado. La monomodo puede alcanzar hasta unos 100 km, mientras que la multimodo llega a unos 2 km. También influye la potencia del transmisor, la calidad del cable y la velocidad de transmisión
