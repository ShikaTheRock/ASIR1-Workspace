La minería de datos es básicamente un proceso para sacarle sentido a grandes cantidades de datos y usarlos para tomar decisiones. Tiene varios pasos:
Primero defines qué quieres conseguir, porque sin un objetivo claro no tiene sentido ponerse a analizar nada. A partir de ahí recopilas los datos que necesitas según ese objetivo.
Luego viene la parte más pesada, que es limpiar esos datos. Los datos reales están llenos de errores, huecos y duplicados, así que hay que dejarlos presentables antes de hacer nada con ellos.
Con los datos listos se aplican los algoritmos, que pueden ser de muchos tipos dependiendo de lo que busques: agrupar clientes parecidos, predecir comportamientos, encontrar productos que se compran juntos, detectar fraudes, etc. El resultado es un modelo que refleja los patrones que hay en los datos.
Ese modelo se evalúa para ver si funciona bien. Si no da buenos resultados se ajusta o se cambia, y se repite el proceso hasta que sea suficientemente preciso.
Finalmente los resultados se comunican de forma clara a quien tenga que tomar decisiones, y se aplican. Por ejemplo, un banco usa el modelo para detectar transacciones sospechosas, o un supermercado lo usa para colocar mejor los productos.
Y esto no es un proceso que se hace una vez y ya. Los datos cambian, los comportamientos cambian, así que los modelos hay que revisarlos y actualizarlos con el tiempo.
