## TAREA 04

Averigua cuál es la diferencia entre una red de ordenadores y un sistema distribuido.

1. Red de ordenadores

Qué es: Es un conjunto de computadoras conectadas entre sí para compartir recursos (archivos, impresoras, acceso a Internet, etc.).

Propósito: Solo permite que las computadoras se comuniquen y compartan cosas.

Ejemplo: Las computadoras de una escuela conectadas entre sí para compartir archivos y recursos.

2. Sistema Distribuido

Qué es: Es un conjunto de computadoras que trabajan juntas como si fueran una sola, colaborando para resolver tareas más grandes o complejas.

Propósito: Las computadoras trabajan juntas de manera coordinada para hacer algo más grande o más rápido.

Ejemplo: Los servidores de Google trabajando juntos para ofrecerte los resultados de búsqueda.

Red de ordenadores: Solo conecta dispositivos.

Sistema distribuido: Conecta dispositivos para que trabajen juntos en tareas complejas.
