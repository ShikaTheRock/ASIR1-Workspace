# TAREA 01
¿Qué es la IEEE y cuáles son las siete normativas IEEE más empleadas en redes de área local de cualquier tipo?

## IEEE 802.1 – Arquitectura y control de redes LAN

Define los aspectos generales de la arquitectura de red, la interconexión entre redes LAN y MAN, y los protocolos de control y gestión del tráfico.
Incluye mecanismos de seguridad, priorización de tráfico y control de acceso a la red.

## IEEE 802.1D – Spanning Tree Protocol (STP)

Es un subestándar de 802.1 que define el Protocolo Spanning Tree (STP), usado en switches para evitar bucles en topologías de red con caminos redundantes.
Permite que solo un camino esté activo entre dos puntos, garantizando estabilidad y redundancia controlada.

## IEEE 802.1Q – VLAN (Virtual LAN)

Establece el estándar para la segmentación de redes mediante VLANs.
Permite dividir una red física en varias redes lógicas separadas, mejorando la seguridad, organización y eficiencia del tráfico de red.
Define también el concepto de etiquetado (tagging) en tramas Ethernet para identificar la VLAN a la que pertenece cada paquete.

## IEEE 802.2 – Capa de enlace lógico (LLC)

Define la subcapa LLC (Logical Link Control) dentro de la capa de enlace de datos del modelo OSI.
Se encarga de la identificación de protocolos de red superiores (como IP o IPX) y del control del flujo y errores entre dispositivos.

## IEEE 802.3 – Ethernet

Es el estándar más común para redes LAN con cable.
Define el método de acceso CSMA/CD (Carrier Sense Multiple Access with Collision Detection) y las especificaciones físicas del cableado (par trenzado, fibra óptica, etc.).
Incluye versiones como:

802.3u → Fast Ethernet (100 Mbps)

802.3ab → Gigabit Ethernet (1000 Mbps)

802.3ae → 10 Gigabit Ethernet

## IEEE 802.11 – Wi-Fi

Define los estándares para redes inalámbricas (WLAN).
Permite la comunicación sin cables entre dispositivos mediante ondas de radio.
Algunas versiones son:

802.11b / g / n → bandas de 2.4 GHz

802.11ac / ax → bandas de 5 GHz y 6 GHz (Wi-Fi 5 y Wi-Fi 6)

## IEEE 802.16 – WiMAX

Define el estándar para redes de área metropolitana inalámbricas (WMAN), conocido como WiMAX (Worldwide Interoperability for Microwave Access).
Permite la transmisión de datos de alta velocidad a grandes distancias, siendo una alternativa al acceso por cable o fibra en zonas rurales o amplias.
