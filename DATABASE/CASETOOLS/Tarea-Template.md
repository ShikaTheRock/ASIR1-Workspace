# Que es una herramienta Case?

Las herramientas CASE son un conjunto de aplicaciones informticas, usadas para automatizar actividades de el ciclo de vida de desarrollo de sistemas (SDLC). Las herramientas CASE son usadas por los Directores de proyectos de software, analistas e Ingenieros para desarrollar sistemas de software.

# De que tipos existen?

Herramientas Upper CASE - Las Herramientas Upper CASE se usan en las etapas de planificacion, anlisis y diseño del SDLC.

Herramientas Lower CASE - Las Herramientas Lower CASE se usan en la implementacion, las pruebas y en el mantenimiento.

# Para que se usan?

Para facilitar que a partir de un diagrama de entidad-relacion, pulsando un boton y eligiendo el lenguaje, cree un script con los comandos de relacion de las tablas.

# Que herramientas case gratuitas existen?

## MySQL Workbench

Herramienta oficial de Oracle para modelado, diseño y administración de bases de datos MySQL.

Permite crear diagramas entidad-relación (EER), generar scripts SQL automáticamente y hacer ingeniería directa e inversa de bases de datos.

## DBDesigner 4

Herramienta de diseño visual de bases de datos que combina modelado de datos, creación de diagramas y generación de código SQL.

Es ligera y fácil de usar, ideal para estudiantes o proyectos pequeños.

## pgModeler

Especializada en PostgreSQL, permite modelar bases de datos a nivel gráfico y luego exportar el modelo a código SQL.

Soporta ingeniería directa e inversa y es multiplataforma (Linux, Windows, macOS).

# Que herramientas case de pago existen?

## ER/Studio Data Architect

Una de las más potentes a nivel empresarial. Permite modelar bases de datos complejas, ingeniería directa e inversa, documentación automática y colaboración entre equipos. Muy usada en grandes corporaciones.

## Toad Data Modeler

Herramienta versátil que soporta muchos SGBD. Destaca por ser más ligera y accesible que ER/Studio, pero igualmente potente para diseño de bases de datos y generación de scripts SQL.

## Navicat Data Modeler

Famosa por su interfaz moderna y sencilla. Permite crear diagramas EER, ingeniería directa e inversa y trabajar con múltiples bases de datos. Muy usada por profesionales que buscan potencia sin tanta complejidad.
